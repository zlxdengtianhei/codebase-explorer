# Agent 执行指南

> 本文件是给执行研究任务的 Agent 看的通用指引

## 你的任务

你正在为 `codebase-explorer` 项目执行一个深度研究任务。请阅读分配给你的任务文件（如 `01_code_graph_tools.md`），然后：

1. **按照搜索关键词进行多轮搜索**
2. **深入阅读指定的资源**（URL、GitHub repo、论文等）
3. **将结果保存到** `results/<task_number>_<topic>.md`

## 输出格式要求

每个结果文件必须包含：

```markdown
# [任务标题]

> 调研时间：[时间]
> 调研覆盖：[列出搜索和阅读的内容]

## 核心发现

[最重要的 3-5 条结论]

## 详细内容

[按任务要求的结构组织]

## 引用来源

[所有参考的 URL，有简要说明]

## 遗留问题

[调研中未能解决的问题，需要进一步研究的方向]
```

## 通用规则

1. **交叉验证**：不要只看 README 就下结论。查看 GitHub issues、社区讨论、实际用户反馈。
2. **引用必须有 URL**：所有声称的事实必须有来源链接。
3. **区分"声称的"和"验证的"**：如果工具声称支持某功能但你无法验证，标注为"声称但未验证"。
4. **优先级**：先完成任务文件中标为"必须"的内容，再做"可选"的。
5. **代码示例必须可运行**：不要给伪代码，给实际可执行的代码。
6. **中文为主**：用中文撰写报告，专有名词和代码保持英文原文。

## 项目背景（供上下文参考）

本项目 `codebase-explorer` 要构建一个**本地 MCP Server + Agent Skill** 的解决方案：

- **目标**：让 AI Agent 能够系统性地分析整个代码库，生成渐进式披露的架构文档
- **关键约束**：
  - 完全本地运行（无外部服务）
  - 多 Agent 协作（不同会话分析不同模块）
  - 确定性的完整性检查（知道哪些分析了，哪些没分析）
  - 兼容 Claude Code / Gemini CLI / OpenCode 等工具
- **技术栈**：Python, FastMCP, graph-sitter (或 tree-sitter), SQLite
- **输出格式**：Markdown 文档，层级结构 (INDEX → OVERVIEW → DETAIL)
