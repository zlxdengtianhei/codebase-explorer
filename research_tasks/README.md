# 深度研究任务集

> 创建时间：2026-03-21
> 项目：codebase-explorer — 多Agent代码库探索与渐进式架构文档生成

## 概述

本目录包含 7 个独立的深度研究任务，覆盖了实现 codebase-explorer 所需的所有技术领域。
每个任务可以由不同的 Agent 独立执行，结果保存在 `results/` 目录下。

## 任务列表

| #   | 文件                              | 研究领域                      | 预期产出                    |
| --- | --------------------------------- | ----------------------------- | --------------------------- |
| 1   | `01_code_graph_tools.md`          | 代码图谱/依赖分析工具深度调研 | 工具对比矩阵 + 最佳选型建议 |
| 2   | `02_auto_module_grouping.md`      | 代码自动模块分组算法          | 算法选型 + 参考实现代码     |
| 3   | `03_docagent_architecture.md`     | DocAgent 多Agent架构深度分析  | 可复用的设计模式提取        |
| 4   | `04_progressive_doc_standards.md` | 渐进式披露文档设计标准        | 文档模板规范 + 索引连接方式 |
| 5   | `05_mcp_server_patterns.md`       | MCP Server 实现最佳实践       | FastMCP 代码模式 + 注意事项 |
| 6   | `06_agent_skill_design.md`        | Agent Skill (SKILL.md) 设计   | 跨工具兼容的 Skill 设计方案 |
| 7   | `07_context_budget_strategies.md` | 上下文预算与代码分片策略      | 实际可行的代码量控制方案    |

## 执行方式

每个任务文件包含：

- **研究目标**：要解决的核心问题
- **搜索关键词**：多组中英文搜索 prompt
- **深入方向**：需要阅读的具体 URL / repo / 论文
- **产出要求**：结果文件的格式和存放位置
- **质量标准**：必须包含的内容和交叉验证要求

Agent 应将研究结果保存到 `results/<task_number>_<topic>.md`，例如：

```
results/01_code_graph_tools.md
results/02_auto_module_grouping.md
...
```

## 任务间依赖

```
01 (图谱工具) ──┐
02 (模块分组) ──┤──→ 04 (文档标准) ──→ 06 (Skill设计)
03 (DocAgent) ──┘          │
                           ↓
05 (MCP Server) ──→ 07 (上下文预算)
```

### 前置结果读取机制

任务 04-07 的文件中都包含 `⚠️ 前置依赖` 章节，**明确要求 Agent 在开始调研前先读取 `results/` 目录下的前置结果**：

| 任务 | 需要先读取的结果      | 不存在时的处理                 |
| ---- | --------------------- | ------------------------------ |
| 01   | 无（独立）            | -                              |
| 02   | 无（独立）            | -                              |
| 03   | 无（独立）            | -                              |
| 04   | 01, 02, 03 的结果     | 可独立执行，标注"待对齐"       |
| 05   | 01, 03, 04 的结果     | 可独立执行，标注"待对齐"       |
| 06   | **所有** 01-05 的结果 | 可先调研格式，草案等齐全后再写 |
| 07   | 01, 02, 05 的结果     | 可独立执行，标注"待对齐"       |

### 推荐执行顺序

1. **第一批（并行）**：任务 01 + 02 + 03 → 同时启动 3 个 Agent
2. **第二批（并行）**：任务 04 + 05 + 07 → 等第一批完成后启动
3. **第三批（单独）**：任务 06 → 等前面全部完成后执行（整合性任务）

- **所有任务都可以独立执行**，只是有了前置结果会更精确
