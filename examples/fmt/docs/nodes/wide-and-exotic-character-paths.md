# Wide and Exotic Character Paths

**Capability.** Provides wide-character and non-char formatting helpers, forwarding, and exotic-character format and print paths.

Use this group for wchar_t and exotic-character formatting support. Helpers and forwarding cover wide strings, while exotic formatting handles character types beyond char and wchar_t.

**Children.**

- [Wide Character Format Helpers](wide-character-format-helpers.md) `wide-character-format-helpers` · 14 unit(s)
- [Wide Format and Print Forwarding](wide-format-and-print-forwarding.md) `wide-format-and-print-forwarding` · 10 unit(s)
- [Exotic Character Formatting](exotic-character-formatting.md) `exotic-character-formatting` · 10 unit(s)

Parent: [Character and Style Formatting](character-and-style-formatting.md)

## Look up code

`RUN` is the run directory. Find `ID` by a unit title on this page (exact names first):
`cbe find --run-dir "$RUN" --term "UNIT_TITLE"`. Then use an `ID` from the results:
`cbe query --run-dir "$RUN" --id "$ID"`; `cbe source --run-dir "$RUN" --id "$ID" --context 2`.
