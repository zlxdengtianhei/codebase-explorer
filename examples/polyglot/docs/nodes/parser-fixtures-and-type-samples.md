# Parser Fixtures and Type Samples

**Capability.** Supplies parser edge-case files and generic-type examples useful for testing language tooling behavior.

Come here for files whose main value is exercising tooling rather than demonstrating a feature to readers. The edge-case fixtures stress parsers with errors, encodings, and trivial statements, while the generics samples show parameterized types and interfaces.

## Look up code

`RUN` is the run directory. Find `ID` by a unit title on this page (exact names first):
`cbe find --run-dir "$RUN" --term "UNIT_TITLE"`. Then use an `ID` from the results:
`cbe query --run-dir "$RUN" --id "$ID"`; `cbe source --run-dir "$RUN" --id "$ID" --context 2`.
