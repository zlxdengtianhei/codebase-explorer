# Polyglot Language Samples Repository

**Capability.** Collects small parallel code samples across many languages to exercise parsing, closures, generics, and basic program structure.

Readers should come here for an overview of the whole repository, which mixes self-contained language demos with fixture-oriented edge-case files. G2 and G3 group the samples; the remaining children are standalone per-language demonstrations of closures, structs, workers, and simple main classes.

## Look up code

`RUN` is the run directory. Find `ID` by a unit title on this page (exact names first):
`cbe find --run-dir "$RUN" --term "UNIT_TITLE"`. Then use an `ID` from the results:
`cbe query --run-dir "$RUN" --id "$ID"`; `cbe source --run-dir "$RUN" --id "$ID" --context 2`.
