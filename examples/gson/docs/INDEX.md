# gson: code map

This repository is Gson, a Java library that converts objects to JSON and back by combining a streaming reader/writer, an in-memory JsonElement tree model, reflective field binding, and a pluggable TypeAdapter framework. The public API and type-resolution module exposes the Gson facade, annotations, and generic TypeToken machinery, while the adapter framework supplies built-in JDK, date/time, enum, and number adapters configured through GsonBuilder and exclusion strategies. Reading and writing infrastructure implement the low-level pull parser and RFC 8259 writer (plus tree-backed variants), and reflective object binding maps arbitrary classes to JSON via field introspection, instance construction, and access filtering.

## Key flows

- **Builder assembles number adapter chain**: GsonBuilder.createFactories wires the Number adapter to its strategy and registers stock JDK adapters via type-token matching. — `GsonBuilder.createFactories` → `NumberTypeAdapter.java-numbertypeadapter-read-write` → `ToNumberStrategy.readNumber`
- **Exact-type factory registration**: The builder registers adapters through factory combinators that match types via TypeToken equality and GsonTypes comparisons. — `GsonBuilder.createFactories` → `TypeAdapters.java-newfactory-class` → `TypeToken.java-typetoken-accessors-and-equality` → `GsonTypes.java-type-equality`
- **Date adapter configuration**: createFactories delegates to addDateTypeAdapters, which installs DefaultDateTypeAdapter support for configured date types. — `GsonBuilder.createFactories` → `GsonBuilder.addDateTypeAdapters` → `DefaultDateTypeAdapter.java-datetype-abstraction`
- **Null-safe atomic adapters**: The builder registers atomic adapters wrapped with nullSafe so null values are handled without invoking the adapter. — `GsonBuilder.createFactories` → `TypeAdapters.java-atomiclongadapter` → `TypeAdapter.nullSafe`
- **Tree reader navigates object members**: JsonTreeReader walks JsonObject members through LinkedTreeMap lookups, using rebalancing to keep the ordered map efficient. — `JsonTreeReader.java-structure-navigation` → `JsonObject.java-jsonobject-read-accessors` → `LinkedTreeMap.java-basic-map-operations` → `LinkedTreeMap.find` → `LinkedTreeMap.rebalance`
- **Writer emits named values**: JsonWriter's value overloads route through property-name handling and the scope stack to emit well-formed output. — `JsonWriter.java-simple-value-overloads` → `JsonWriter.java-property-name-handling` → `JsonWriter.beforeName` → `JsonWriter.java-scope-stack-helpers`
