# JSON Element Exceptions

**Capability.** The JsonNull representation of the JSON null value within the tree model and the runtime exception hierarchy (JsonParseException base, JsonSyntaxException for malformed documents) shared by parsing and binding; includes the annotations package documentation.

Use this subtree for the tree model's null value and for the exception types callers catch when JSON is malformed.

Parent: [JSON Streaming and DOM Representation](json-representation.md)

## Look up code

`RUN` is the run directory. Find `ID` by a unit title on this page (exact names first):
`cbe find --run-dir "$RUN" --term "UNIT_TITLE"`. Then use an `ID` from the results:
`cbe query --run-dir "$RUN" --id "$ID"`; `cbe source --run-dir "$RUN" --id "$ID" --context 2`.
