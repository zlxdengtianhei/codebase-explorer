## Verification Checks

Run these checks after Phase 4 completes:

### Check 1: INDEX.md Structure

```
Read .codebase-docs/INDEX.md and verify:
- [ ] YAML front matter present (project, total_modules, generated_by)
- [ ] Mermaid graph present (```mermaid block)
- [ ] At least one <!-- module-index:{id} --> block per module
- [ ] <!-- codebase-explorer: end --> marker at end of file
```

### Check 2: DETAIL File Existence

```
For each module in get_modules().modules:
- [ ] .codebase-docs/{module_id}/DETAIL.md exists
```

If any DETAIL is missing: re-run Phase 3 for the missing module.

### Check 3: DETAIL Content — Four Sections

```
For each DETAIL.md, for each file block:
- [ ] <!-- file:{filepath} --> marker present
- [ ] #### 功能概述 (Purpose) section present and non-empty
- [ ] #### 数据流 (Data Flow) section present and non-empty
- [ ] #### 核心接口 (Key Interfaces) section present and non-empty
- [ ] #### 依赖关系 (Dependencies) section present and non-empty
- [ ] <!-- end:file:{filepath} --> marker present
```

### Check 4: INDEX Fragment Presence

```
For each DETAIL.md:
- [ ] <!-- index-fragment:{module_id} --> block present
- [ ] Fragment content is non-empty (not just markers)
```

### Check 5: Link Validity

```
For each [→ DETAIL]({module_id}/DETAIL.md) link in INDEX.md:
- [ ] The referenced file exists on disk
```

### Check 6: Source File Coverage

```
Call get_progress()
- [ ] source_file_coverage_percent >= 80
```

## Architecture Principles (Reference)

1. **Separation of Concerns**
   - MCP Server: Deterministic analysis (no LLM)
   - Skill orchestrator: Phase sequencing and sub-agent spawning
   - DETAIL agents: Semantic understanding + doc writing (reads source code)
   - INDEX assembly agent: Semantic review + reorganization (does NOT read source code)

2. **Progressive Disclosure**
   - INDEX.md: Project overview with module map
   - DETAIL.md: Per-module, per-file implementation details
   - No intermediate OVERVIEW layer — two documents only

3. **Token Awareness**
   - Chars / 4 estimation (< 15% error)
   - Modules > 50k tokens: document in two passes
   - Token budget enforced in DETAIL agent via accumulation rule

4. **Idempotency**
   - JSON files regenerated by `analyze_codebase(force_reindex=true)`
   - `state.json` tracks progress for session recovery
   - `doc_operation("update_index")` can be called multiple times safely

- `{module_id}/DETAIL.md` — per-module documentation with four-section per-file analysis
