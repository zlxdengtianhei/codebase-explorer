# Publication provenance

Numbers refer to the original runs; publication copies replace local paths and user names, so recorded byte and observation counts may differ slightly from the sanitized contents.

Evaluation documents retain their original source-reference targets and wording, apart from local-path redaction. Only examples/ source-reference definitions have been converted to pinned upstream GitHub links where a commit is available. Historical scripts use MAGPIE_API_KEY from the environment; WORK (or CBE_WORK_ROOT) selects the reconstructed experiment workspace, and TMP defaults to TMPDIR or /tmp. Scripts are historical reproduction material: only Python compilation has been tested, and original run inputs and optional tools are still required.

SWE-QA embedded question text is retained under Apache-2.0 while standalone question JSONL files and reference answers are excluded, as decided in D-78; this records the explicit publication interpretation of EVAL section 7. E5 project-authored questions and reference answers are included.
