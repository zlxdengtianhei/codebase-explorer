# Help text

**Capability.** Generated help data: the helptxt[] table pairing each option with its description and CURLHELP_* category bitmask, plus the showhelp/hugehelp declarations under USE_MANUAL.

Regenerate rather than hand-edit tool_listhelp.c; the tool's help system consumes the table.

Parent: [Command-line tool](r12-cli-tool.md)

### `tool-listhelp-c-helptext`

`group` · [src/tool_listhelp.c:L1-L895][f1]

Defines the generated helptext[] lookup table consumed by the tool's help system: an array of struct helptxt entries pairing each command-line option string with a one-line description and a bitmask of CURLHELP_* category flags.

Entries are sorted alphabetically by option name and terminated by a {NULL, NULL, 0} sentinel so consumers can detect the end. Some entries are conditionally compiled: four HTTP Message Signature options appear only when CURL_DISABLE_HTTPSIG is undefined, and the IPFS gateway option only when CURL_DISABLE_IPFS is undefined. The file header states the table is generated by 'make listhelp' and must not be edited manually.
